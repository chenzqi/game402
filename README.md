一个纯前端（HTML5 Canvas + 原生 JS）的竖版飞行射击游戏，**零依赖、零构建**，双击 `index.html` 即可开玩。

## 一、运行方式

- **直接打开**：双击 `index.html`（推荐 Chrome / Edge / Firefox）
- **本地服务**（可选）：
  ```bash
  cd D:/ai_test_project/test402-game3
  python -m http.server 8000   # 然后访问 http://localhost:8000
  ```
- **跑测试**：`node test.js`（43 项断言）

## 二、操作

| 按键 | 功能 |
| --- | --- |
| `← ↑ ↓ →` / `W A S D` | 移动飞船 |
| `空格` | 开火（默认已开启自动开火，无需一直按住） |
| `B` | 释放核弹：清空弹幕 + 全场敌人受创 |
| `P` / `Esc` | 暂停 / 继续（切换窗口会自动暂停） |
| `R` | 重新开始 |
| `M` | 开关音效 |
| `F` | 切换自动开火 |

- **鼠标**：在画面上移动即可让飞船跟随（拖动时自动开火）
- **触屏**：手指在画面上拖动 = 相对位移操纵飞机（不会挡住机身），底部按钮提供左右移动 / 核弹 / 暂停

## 三、玩法

- **波次**：敌人成阵型成批来袭，清空一波后进入下一波，波次越高速度、血量、弹幕密度越高。
- **母舰**：每 5 波出现一艘 BOSS，会横向巡航并有三种弹幕阶段（瞄准散射 → 环形爆发 → 高速螺旋），屏幕顶部有专属血条。
- **敌人类型**：
  | 类型 | 行为 | 特点 |
  | --- | --- | --- |
  | 侦察机 | 直线俯冲 | 1 点血，数量多 |
  | 无人机 | 左右摆动 | 不可预测的走位 |
  | 自爆机 | 追踪撞向玩家 | 撞到即受伤 |
  | 战斗机 | 突入后悬停点射 | 会瞄准玩家射击 |
  | 重型机 | 缓慢推进 + 三向散射 | 血厚，掉宝率高 |
  | 母舰 | 巡航 + 多阶段弹幕 | 巨额分数 |
- **道具**（击落敌人随机掉落）：
  - `P` 火力升级（最高 Lv.5，子弹从 1 发增加到 5 发散射）
  - `S` 护盾（抵挡一次伤害）
  - `H` 回复 1 点生命（上限 5）
  - `B` 补充核弹（上限 5）
- **计分**：击落得分 × 连击倍率；连击越高倍率越高（最高 3 倍），每波清空还有波次奖励。最高分记录在浏览器本地。

## 五、实现要点

- **分层的核心逻辑**：所有与画面无关的规则（敌人属性、难度、波次阵型、掉落表、碰撞判定）都放在 `core.js`，不依赖 DOM，因此可以直接用 Node 做单元测试。
- **帧无关的时间步进**：主循环用 `requestAnimationFrame` 的真实时间差驱动（`dt` 上限 34ms，防止切后台回来跳帧），所有运动、冷却、动画都按秒计算。
- **派生的难度曲线**：`difficulty(wave)` 统一给出速度/血量/火力系数，敌人血量 `round(hp × 系数)`、开火间隔 `fire / 系数`，避免到处写魔法数字。
- **阵型化波次编排**：`buildWave()` 生成"延迟 + 横向位置 + 类型"的投放计划，游戏循环按时间依次投放；阵型有横排、V 字、纵列、弧线、散点五种轮换。
- **程序化美术**：飞船、敌机、母舰、子弹、道具全部用 Canvas 路径绘制，没有一张图片资源；爆炸是粒子系统（火花 / 烟雾 / 冲击环），星空是三层视差 + 星云径向渐变。
- **程序化音效**：用 WebAudio 的振荡器与噪声缓冲实时合成射击、爆炸、受伤、拾取、核弹等音效，没有任何音频文件；音频上下文在首次用户操作时才创建（符合浏览器自动播放策略）。
- **对象生命周期管理**：子弹、敌人、粒子都做了越界回收与数量上限（粒子 700），避免长时间游玩后列表无限增长。
- **自适应画布**：逻辑分辨率固定 480×720，按设备像素比渲染，再根据窗口与列宽计算 CSS 尺寸，高分屏锐利、窄屏自动缩排。
