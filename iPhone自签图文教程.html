0先回答你的两个问题

苹果"小号"是什么？

就是另外注册一个 Apple ID（免费，不是开发者账号）。因为签名时要把 Apple ID 的密码交给 Sideloadly 这个第三方工具一次，用小号的话，万一有风险也不会波及你的主号（主号上挂着 iCloud 照片、备忘录、支付方式）。

我能直接用主账号吗？

能，技术上完全一样，签名效果没有任何区别。区别只有一条：你愿不愿意把密码交给这个工具一次。

嫌麻烦 → 直接用主号，绝大多数人都这么干。
想稳妥 → 花 3 分钟注册小号：电脑浏览器打开 https://account.apple.com/ → 创建 Apple ID → 用一个没注册过苹果的邮箱/手机号；地区选中国，付款方式选「无」。不用在手机上登录它，只要在 Sideloadly 里填这个新账号即可。
不要在手机「设置」里退出当前 Apple ID 去换小号——那会把主号登出，影响 iCloud 数据。

需要开发者账号吗？

不需要。免费 Apple ID 就能签，限制是：7 天有效、同时最多 3 个自签 App、7 天内能创建的 App ID 数量有限。

97 天到期怎么办

到期表现：点图标提示「无法验证 App」或直接闪退。解决办法：重复第 4 步再签一次，2~3 分钟。

⚠️ 千万不要先在手机上删除 App！官方 FAQ 确认：用同一个 Apple ID、同一个包覆盖安装，App 会原地升级、最高分等本地数据保留；一旦手动删除，存档就清空了。
